# FlyMail Page Gutter and Collapsed Logo Follow-up Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every desktop top-level page start 20px after the sidebar and keep the FlyMail logo visible when the sidebar is collapsed.

**Architecture:** Correct the shared page-template alignment rules instead of patching individual views. Preserve the existing 1280px management and 960px document maximum widths, but anchor those bounded columns to the left. Keep the collapsed header logo visible at rest and reveal the expand action only on hover or keyboard focus so both controls do not overlap.

**Tech Stack:** Vue 3, scoped/global CSS, Node test runner, Vite, Docker.

## Global Constraints

- Do not change APIs, authentication, mailbox behavior, permissions, or persistent data.
- Desktop page content starts at `var(--page-padding)` (20px) after the sidebar.
- Mobile pages remain edge-to-edge under the existing 960px breakpoint.
- Collapsed sidebar width remains 72px.
- Do not add or upgrade production dependencies.
