# FlyMail 深色模式设计

## 目标

为 FlyMail 增加全局深色模式，并在“设置”页面提供“跟随浏览器、浅色、深色”三种外观选项。首次使用默认跟随浏览器；用户选择在当前浏览器持久化，页面刷新和重新登录后继续生效。

## 方案比较

1. **浏览器本地主题控制器（采用）**：使用 `localStorage` 保存三态偏好，根节点通过 `.dark` 切换主题，跟随模式监听 `prefers-color-scheme`。优点是登录页加载前即可生效、无接口依赖、不会影响多用户邮件数据。
2. **后端用户设置**：可跨设备同步，但登录前无法取得偏好，容易闪烁，还需新增接口字段和数据库读写；本需求没有要求跨设备同步。
3. **仅使用 CSS `prefers-color-scheme`**：实现最少，但无法满足设置页手动切换和持久化。

## 架构

- `frontend/src/utils/theme.ts`：定义 `ThemePreference = 'system' | 'light' | 'dark'`，负责规范化偏好、计算实际主题、持久化、更新根节点和监听系统主题变化。
- `frontend/src/main.ts`：创建 Vue 应用前初始化主题，避免首屏颜色闪烁。
- `frontend/src/views/Settings.vue`：展示三项外观选择，选择后立即调用主题控制器并保存，不复用后端“保存设置”按钮。
- `frontend/src/styles/macos.css`：补充深色变量、浏览器原生控件 `color-scheme`、滚动条和通用组件深色状态。
- `frontend/src/App.vue`：把应用壳、侧栏、顶部栏、通知抽屉、确认框等硬编码浅色改为现有设计变量。

## 数据流

1. 页面脚本加载后读取 `localStorage['flymail_theme']`。
2. 无值或非法值按 `system` 处理。
3. `system` 使用 `window.matchMedia('(prefers-color-scheme: dark)')` 决定实际主题并订阅变化。
4. `light` 或 `dark` 直接应用，并停止依赖系统变化。
5. 实际深色时给 `<html>` 添加 `dark` 类，同时设置 `color-scheme`；浅色时移除该类。
6. 设置页选择新值后立即更新，无需刷新。

## 视觉规则

- 深色背景分为主背景、次背景、卡片背景三级，不使用纯黑。
- 文本、边框、悬停、选中、阴影均通过现有 CSS 变量覆盖。
- 品牌蓝、成功、警告、危险等语义色保持一致，只调整透明背景和对比度。
- 邮件正文属于外部 HTML 内容，不强制反色，避免破坏发件人排版和图片。

## 测试与验收

- 单元测试先验证：非法/缺失偏好默认 `system`；三态实际主题解析；保存后根节点类与存储同步；跟随模式响应系统变化；固定主题忽略系统变化。
- `vue-tsc && vite build` 通过。
- 后端全量单元测试通过。
- Docker 镜像构建并用独立临时数据目录启动，健康检查返回版本 `0.0.2`，MySQL 与 `/data` 持久化验证通过。
- README 当前能力增加深色模式说明。

## 边界

- 主题偏好只保存在浏览器本地，不跨浏览器或设备同步。
- 不修改数据库结构、认证方式、邮箱数据或 `/Docker/flymail/data`。
