# FlyMail 响应式侧边栏设计

## 目标

修复移动端顶部横向导航、账号标签和桌面邮件列表被强行压缩造成的布局问题，同时为桌面端增加可记忆的主导航折叠功能。

## 已确认边界

- 桌面端只允许隐藏 FlyMail 主导航栏。
- 邮件管理中的账号与文件夹侧栏始终保留。
- 移动端主导航改为左侧抽屉，不再显示顶部横向导航胶囊。
- 移动端账号和文件夹入口合并到同一抽屉中，不再显示顶部横向账号标签。
- 点击邮件继续进入独立详情视图，不增加右侧常驻预览栏。
- 不修改后端接口、认证、数据库和 `/data` 持久化结构。

## 桌面端交互

顶部标题左侧增加主导航切换按钮。主导航展开时保持现有 220px 宽度；折叠时网格主导航列收缩为 0，内容区占满释放空间，邮件文件夹侧栏仍保持显示。折叠状态写入 `localStorage` 的 `flymail_sidebar_collapsed`，刷新页面后恢复。

## 移动端交互

960px 及以下时，主导航变为固定定位的左侧抽屉。顶部左侧菜单按钮打开抽屉，点击遮罩、导航项或按下 Escape 关闭。抽屉包含品牌、主导航、当前邮件账号和文件夹列表。选择账号或文件夹后通过页面事件通知 `MailList.vue` 复用现有账号切换、文件夹加载和邮件刷新逻辑。

## 移动端邮件列表

移除顶部横向账号标签。列表工具栏保持单行但只展示写邮件、当前文件夹、搜索、刷新和必要操作。邮件行取消固定 560px 最小宽度，改成移动端专用三行布局：发件人和时间、主题、轻量状态信息；页面不得产生水平滚动。

## 状态与事件

- `sidebarCollapsed`: 桌面主导航折叠状态，持久化到 `localStorage`。
- `mobileSidebarOpen`: 移动端抽屉临时状态，不持久化。
- `isMobileLayout`: 由 `window.innerWidth <= 960` 更新。
- `flymail-mail-navigation`: App 抽屉向邮件列表发送账号或文件夹切换请求。

## 验收标准

1. 桌面端可以折叠和恢复主导航，刷新后保留状态。
2. 桌面端折叠主导航后，邮件账号与文件夹侧栏仍显示。
3. 移动端不再出现顶部横向主导航和账号标签。
4. 移动端抽屉可查看主导航、账号和文件夹，并能完成切换。
5. 移动端邮件列表宽度不超过视口，无横向滚动。
6. 现有详情、搜索、筛选、多选、分页、刷新和同步行为无回归。
7. 前后端测试、前端构建、Docker 构建和容器持久化验证通过。
