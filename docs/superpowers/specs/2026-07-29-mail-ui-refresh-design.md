# FlyMail 邮件界面重构设计

## 目标

在不改变邮件读取、筛选、搜索、多选、分页和“点击邮件进入详情页”行为的前提下，重构桌面端视觉层级，使 FlyMail 更接近现代桌面邮件客户端，同时保持现有移动端交互可用。

## 已确认的设计边界

- 不增加右侧常驻邮件预览栏。
- 点击邮件后继续使用当前列表页切换到详情页的方式。
- 邮件列表工具栏继续放在邮件列表卡片内部，不移动到页面标题栏下方形成独立横条。
- 不修改后端接口、数据库结构、认证方式、邮箱同步逻辑或持久化目录。
- 不引入新的前端 UI 依赖。

## 页面结构

### 应用侧栏

左侧主导航使用“邮件 / 管理 / 系统”分组。每个导航项增加线性图标，当前项使用低饱和蓝色背景和蓝色文字，避免整块高亮过度抢占注意力。品牌区保持 FlyMail 图标、名称和 Docker 多用户版说明。

### 顶部标题栏

标题栏左侧仅展示当前页面标题。右侧将原来的“通知 / 修改密码 / 退出登录”三个并列按钮收拢为通知图标和用户菜单。用户菜单显示用户名、角色、修改密码和退出登录入口。

### 邮件文件夹栏

桌面端文件夹栏增加“文件夹”标题和当前邮箱账号切换区域。文件夹条目增加图标，激活项使用克制的蓝色表面。多账号切换保留现有 `switchAccount` 行为，不改变账号和文件夹状态管理。

### 邮件列表工具栏

继续使用现有单行工具栏结构：左侧为写邮件、多选、当前文件夹信息和筛选项，右侧为搜索、全部已读、刷新和连接状态。只调整间距、圆角、背景和响应式收缩，不拆成页面级独立工具条。

### 邮件列表行

邮件行采用更清晰的列结构：选择入口、头像与发件人、主题、附件、未读状态和日期。未读邮件保留粗体和小型蓝色状态点，降低黄色状态标签的视觉权重；已读邮件不再使用大面积不同底色。悬停和选中状态使用表面层级变化。

## 响应式策略

- 桌面端维持主导航 + 文件夹栏 + 邮件列表的布局。
- 960px 以下继续沿用当前横向主导航和单列内容布局。
- 768px 以下继续使用当前文件夹底部弹层、横向可滚动邮件列表和详情页返回交互。
- 不改变移动端手势、分页、筛选下拉和详情页结构。

## 可访问性与动效

- 图标按钮保留 `title`，新增用户菜单按钮提供明确文本和可见焦点。
- 交互动画限定在 150–200ms 的颜色、背景和轻微位移变化。
- 尊重 `prefers-reduced-motion`，不增加持续动画。
- 颜色对比继续使用现有浅色/深色设计变量。

## 验收标准

1. 邮件点击后仍进入现有详情页，不出现右侧常驻预览栏。
2. 邮件列表工具栏仍位于邮件列表卡片内部。
3. 主导航具备分组、图标和清晰的当前项状态。
4. 通知、修改密码和退出登录功能全部保留，后两者位于用户菜单中。
5. 多账号切换、文件夹切换、搜索、筛选、多选、刷新和分页行为不变。
6. 前端测试和构建通过，后端测试无回归。
7. Docker 镜像和临时容器验证通过，`/data` 持久化不受影响。
