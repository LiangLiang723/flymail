# 同步卡片操作区与侧边栏版本显示设计

## 目标

只调整两个局部界面问题：

1. 同步管理卡片减少按钮拥挤，把次要与危险操作收进“更多”菜单。
2. 删除侧边栏用户区域下方的 FlyMail 版本号。

不修改同步任务状态判断、接口调用、确认弹窗、权限、后端、数据库或持久化数据。

## 同步卡片操作区

每张同步任务卡片右上角只直接显示当前最重要、且真实可执行的状态操作：

- `running`、`pending`：显示“暂停”。
- `paused`：显示“继续”。
- `failed`：显示“重试”。
- 其他状态：不显示暂停/继续占位按钮。

操作区末尾始终显示一个带可访问名称的“更多操作”按钮。点击后打开当前卡片自己的菜单，菜单内容为：

- “刷新同步”：调用现有 `refreshSync(item)`，完整同步运行时保持禁用。
- “清空同步数据”：调用现有 `clearJob(item)`，使用危险操作样式；清空任务运行时保持禁用。

菜单行为：

- 同一时间只打开一张卡片的菜单。
- 再次点击当前更多按钮可关闭菜单。
- 点击菜单外部关闭。
- 按 `Escape` 关闭。
- 执行任一菜单操作前先关闭菜单。
- 菜单定位在操作按钮下方并靠右，不挤占卡片标题和状态徽标。
- 移动端沿用相同结构，菜单宽度受视口限制，不产生横向溢出。

保留现有确认弹窗、成功/失败提示、禁用账号提示和接口调用逻辑。

## 侧边栏版本号

删除 `AppSidebar.vue` 底部的版本信息节点，并移除已无用途的 `appVersion` 属性。同步清理：

- `App.vue` 向侧边栏传递的 `app-version` 属性。
- `App.vue` 中仅为侧边栏展示服务的 `appVersion` 常量。
- `app-shell.css` 中 `.sidebar-version` 的桌面及响应式样式。

版本仍由 `/api/health`、关于页和构建元数据提供，本次只移除侧边栏重复显示。

## 测试与验收

新增或更新前端静态回归测试，验证：

- 同步卡片不再渲染禁用的“暂停/继续”占位按钮。
- 刷新和清空操作位于更多菜单。
- 更多按钮具备明确的 `aria-label`。
- 菜单支持点击外部和 `Escape` 关闭。
- 侧边栏不再包含 `.sidebar-version` 和版本属性。
- `App.vue` 不再传递侧边栏版本参数。

完成后执行前端全量测试、前端生产构建、后端回归测试、Shell 和 Docker Compose 检查、镜像构建及独立临时容器验证。正式部署复用 `/Docker/flymail/data`，不会迁移或删除数据。
