# FlyMail V2 真实邮箱、代理与浏览器验收手册

## 目标

本手册用于在不泄露账号、授权码、OAuth 令牌、代理凭据、邮件内容或通知端点秘密的前提下，对 FlyMail V2 的真实服务商与浏览器能力做发布前验收。

健康接口通过只表示 FlyMail API、MySQL、Worker 心跳和对象目录可访问，不表示第三方邮箱、OAuth、代理、通知渠道或浏览器流程已经可用。

## 状态定义

| 状态 | 含义 |
|---|---|
| `pass` | 已在指定真实环境完成并满足验收条件 |
| `fail` | 已执行但行为不符合验收条件 |
| `blocked` | 缺少隔离账号、端点、代理、浏览器或人工设备，未执行真实验证 |
| `limitation` | 当前设计明确不支持或只支持降级路径 |
| `contract-pass` | 仅自动化合同、假 Provider 或静态 UI 测试通过，不能替代真实验证 |

## 安全准备

1. 只使用专用测试邮箱和通知端点，不使用生产账号。
2. 凭据只通过交互式秘密注入或本机未提交的环境文件提供。
3. 禁止把邮箱地址、主题、Message-ID、授权码、OAuth 令牌、代理账号密码、Webhook URL 或通知密钥写入 Git、命令历史、日志和结果文档。
4. 验收数据目录必须独立于 `/Docker/flymail/data`。
5. 真实发送只发往受控测试收件箱；每次测试使用唯一但不记录原值的本地标识。
6. 验收完成后撤销临时令牌、删除测试通知端点并清理临时容器。

## 服务商矩阵

需要覆盖以下插件：

- Gmail
- Outlook / Microsoft
- QQ 邮箱
- 网易邮箱（163、126、188、yeah.net 变体）
- iCloud 邮箱
- 新浪邮箱（sina.com、sina.cn 与 VIP 变体）
- Generic IMAP/SMTP

每个可用服务商至少验证：

1. 密码、授权码或 OAuth 授权。
2. IMAP 与 SMTP 端点、TLS/STARTTLS 和认证失败分类。
3. 特殊邮箱映射。
4. 初始摘要同步和增量同步。
5. IDLE；不支持时验证轮询降级。
6. 已读、星标、移动、归档、垃圾箱和永久删除。
7. Gmail 标签或其他服务商的保守文件夹语义。
8. 正文、CID 内嵌图片、普通附件按需获取和显式 raw `.eml`。
9. SMTP 发送、Message-ID、服务商自动保存或 IMAP APPEND 已发送副本。
10. SMTP DATA 后断线进入结果不确定状态，不能直接重复发送。
11. 授权过期、重新授权和限流提示。
12. FlyMail 重启后游标、任务、租约和缓存状态恢复。

## 代理验证

对具备受控 HTTP CONNECT 代理的测试账号验证：

- OAuth 授权、令牌交换和刷新使用当前用户代理。
- IMAP、SMTP 和 IDLE 使用当前账号或用户代理。
- 代理认证信息不出现在日志、错误响应和诊断接口。
- 代理只影响外部邮箱或显式选择的通知渠道，不影响内部 MySQL、API 和对象目录。
- 非 HTTP/HTTPS 代理、私网目标、回环地址和云元数据地址被拒绝。

## 通知与图床验证

分别验证站内通知、Bark、Telegram、企业微信、钉钉、飞书和通用 Webhook。外部渠道必须使用安全测试端点。

检查：

- 渠道和规则均启用时才投递。
- 代理复用为显式选择。
- 重试、终态和结果不确定状态不会重复投递。
- 日志不包含 URL 查询秘密、令牌和正文。
- `flymail-imgbed` 或通用 HTTPS 图床上传成功时返回临时引用。
- 上传失败时降级为纯文字。
- 所有渠道终态后释放临时图片引用。

## 浏览器与视口矩阵

需要记录执行日期和精确浏览器版本：

- 桌面 Chrome
- 桌面 Edge
- 桌面 Firefox
- 桌面 Safari
- iOS Safari
- Android Chrome

每个可用浏览器至少检查：登录、资料与头像、账号密码/OAuth/代理、账号图标、联系人自动完成、响应式导航、线程列表与详情、图片查看器、打印/PDF、全部已读、写信键盘操作、浏览器附件上传、授权 `/data` 路径导入、搜索、通知中心与设置、冲突处理、关于页、PWA 安装和服务不可达静态壳、备份检查。

## 无障碍人工验收

至少完成：

- 全键盘操作和可见焦点。
- 一个桌面屏幕阅读器。
- 对话框、抽屉和查看器关闭后的焦点恢复。
- 200% 缩放。
- 减少动画。
- 高对比度或强制颜色模式。
- 触控目标和移动端横向溢出检查。

## 结果记录规则

结果文档只记录：服务商或浏览器名称、状态、日期、构建 SHA、行为摘要和不含标识符的错误类别。不得记录账号地址、主题、Message-ID、服务器原始响应、代理 URL、通知端点或任何凭据。

真实验证被阻塞时，必须明确写出缺失资源，不能把自动化合同测试替代为真实通过。
